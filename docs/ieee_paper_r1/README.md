# R1 IEEE manuscript (`docs/ieee_paper_r1/`)

This directory holds the **R1** conference manuscript: a pre-registered,
controlled component-level evaluation of the DecisionGPT goal-to-strategy
pipeline on a synthetic benchmark, reporting a **negative** primary result for
the tested deterministic multi-agent configuration.

It is **separate from** `docs/ieee_paper/`, which is the frozen V1-era
manuscript and is not modified.

## Project scope

R1 asks which components of the pipeline carry measurable decision value on an
independent exogenous objective, after correcting a diagnosed non-responsiveness
in the decision-simulation layer with a minimal, data-estimated elasticity model
(the *research-only* R1 correction). It establishes component ordering, the sign
/ interval / robustness of the D-vs-B contrast, and an associational mechanism
localisation. It establishes **nothing** about real-world / SME / customer / ROI
/ causal / deployment / human-decision / LLM effects, and does not claim
DecisionGPT is validated, superior, or effective. Production configuration
(`R0`/`D0`) is unchanged.

## Reproducing the analysis (no experiment rerun)

Reproducing the paper's statistics requires **only the frozen raw R1 results**;
re-running the locked experiment is neither necessary nor permitted as part of
the publication package.

```bash
# 1. re-derive all statistics from the frozen raw results
python scripts/run_eval_r1.py analyze          # -> experiments/r1/statistical_results.json, mechanism_results.json
python scripts/run_eval_r1.py robustness        # -> experiments/r1/robustness_results.json (reads stored perturbed runs)

# 2. independent recomputation (no reuse of the precomputed summaries)
python scripts/run_eval_r1.py audit             # -> experiments/r1/MACHINE_AUDIT.md  (26/26)
# experiments/r1/independent_recheck.json        # 75/75 checks, produced by the recheck script

# 3. figures
python scripts/r1_figures.py all                # -> docs/figures/r1_figure{1..5}.svg from experiments/r1/figure_data.json
python scripts/r1_figures_to_pdf.py             # -> docs/ieee_paper_r1/figures/r1_figure{1..5}.pdf

# 4. claim / forbidden-term scan
python scripts/scan_r1_claims.py                # -> experiments/r1/forbidden_term_scan.json  (0 prohibited)
```

### Compiling the PDF

```bash
cd docs/ieee_paper_r1
latexmk -pdf main.tex        # or: pdflatex main; bibtex main; pdflatex main; pdflatex main
```

Requires `IEEEtran.cls` + `IEEEtran.bst` (TeX Live / MiKTeX / Overleaf) and
`graphicx, amsmath, amssymb, array, booktabs, url, hyperref`.

> **Build-environment note.** At the time this package was finalised, no LaTeX
> toolchain (`pdflatex` / `bibtex` / `latexmk`) was available, so the PDF was
> **not compiled here**. The manuscript passed structural validation (balanced
> environments, every `\ref` resolves to a `\label`, every `\cite` resolves in
> `references.bib`), a numerical cross-check against the frozen artifacts
> (66/66: 59 headline + 7 per-family optimal-action), and the forbidden-term
> scan (0 prohibited). Compile on any standard TeX install.

## Distinction: reproducing analysis vs rerunning the experiment

- **Reproducing the analysis** (permitted, and the basis of every number in the
  paper): run the `analyze` / `audit` / figure / scan steps above against the
  frozen `results.json`. Deterministic; fixed seeds.
- **Rerunning the locked experiment** (NOT part of this package, NOT permitted
  for publication): the locked R1 test was executed exactly once. It must not be
  re-run, re-seeded, extended, retuned, or repeated for confirmation.
