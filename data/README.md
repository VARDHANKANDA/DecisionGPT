# `data/` — DecisionGPT datasets

Two clearly separated sources. **Synthetic ≠ real** — the Research Console
and the paper must never blur them.

```
data/
├── platform/          # bundled SYNTHETIC datasets (controlled, reproducible)
│   ├── forecasting/   #   platform-forecasting-v1  (sales_timeseries.csv + metadata.json)
│   ├── churn/          #   platform-churn-v1        (customers.csv + metadata.json)
│   └── {marketing,pricing,inventory,causal,benchmarks}/  (.gitkeep — none yet)
│
├── external/          # EXTERNAL BENCHMARK datasets (real / regional / mixed)
│   ├── uci_online_retail/   raw/(gitignored) processed/*.csv metadata.{json,md}
│   ├── m5_forecasting/       raw/(gitignored) processed/*.csv metadata.{json,md}
│   └── regional_retail/      raw/(gitignored) processed/*.csv metadata.{json,md}
│
└── research_uploads/  # runtime store for datasets uploaded via the Research
                        # Console (gitignored)
```

## `platform/` — synthetic, controlled
Generated by `scripts/generate_platform_data.py` (seed 42). Used for the
reproducible baseline experiments and the **known causal ground truth**.
`evidence_level: SYNTHETIC`. **Never removed or replaced.**

## `external/` — real-world / regional benchmarks
Added to strengthen predictive evaluation on non-synthetic data. Each folder:

| Dataset | Country | `data_type` | Raw source | Supported tasks |
|---|---|---|---|---|
| UCI Online Retail | UK | real | UCI ML Repo 352 (CC BY 4.0) | forecasting, customer RFM, **derived** churn (optional) |
| M5 Forecasting | USA | real | M5 competition (Walmart), via Nixtla mirror | forecasting benchmark |
| Supermarket Sales | **Myanmar (not India)** | mixed | Plotly datasets repo (MIT) | forecasting (small), margin analytics |

- **`raw/` is never modified** and is gitignored (~580 MB total). Re-download per `docs/DATASET_DOWNLOAD_INSTRUCTIONS.md`.
- **`processed/*.csv`** are committed, small, and produced *only* by `scripts/build_external_datasets.py` (adapters in `ml/preprocessing/`, fixed seed 42, transforms documented in each `metadata.md`).
- Register into the existing Dataset Registry with `scripts/register_external_datasets.py`; benchmark‑train with `scripts/run_external_benchmarks.py` (all resulting models are `experimental`).

## Honesty rules (see `AGENTS.md`, `docs/DATASET_INTEGRATION_AUDIT.md`)
- No external dataset feeds the SME Digital Twin / Causal Graph / Multi‑Agent engines; those keep the synthetic controlled scenarios.
- `marketing_spend` / `promotion_flag` are held at `0` for every external forecasting adapter — those datasets carry no such signal; it is **not invented**.
- UCI churn is a **DERIVED** inactivity label with a strict observation/holdout time split; it does **not** replace `platform-churn-v1`.
- Supermarket Sales is **Myanmar**, integrated as a regional benchmark. It is **not** an Indian dataset. See `docs/DATASET_DOWNLOAD_INSTRUCTIONS.md §4` for adding a genuine Indian dataset.
