# `data/` — DecisionGPT datasets

DecisionGPT's research focus is **Indian SMEs**. The evaluation strategy is:

```
REAL INDIAN DATA  +  CONTROLLED SYNTHETIC DATA
```

**Synthetic ≠ real, and non-Indian ≠ Indian** — the Research Console and the
paper must never blur them.

```
data/
├── platform/          # bundled SYNTHETIC datasets (controlled, reproducible)
│   ├── forecasting/   #   platform-forecasting-v1  (sales_timeseries.csv + metadata.json)
│   ├── churn/          #   platform-churn-v1        (customers.csv + metadata.json)
│   └── {marketing,pricing,inventory,causal,benchmarks}/  (.gitkeep — none yet)
│
├── external/
│   ├── india_mandi_prices/          # ACTIVE — real Indian benchmark
│   │       raw/(gitignored) processed/*.csv metadata.{json,md}
│   └── _retired_non_indian/          # RETIRED_NON_INDIAN_BENCHMARK (kept for reproducibility only)
│           m5_forecasting/  uci_online_retail/  regional_retail/
│
└── research_uploads/  # runtime store for datasets uploaded via the Research
                        # Console (gitignored)
```

## `platform/` — synthetic, controlled
Generated by `scripts/generate_platform_data.py` (seed 42). Used for the
reproducible baseline experiments and the **known causal ground truth**.
`evidence_level: SYNTHETIC`. **Never removed or replaced.** These back the
causal-graph, Digital-Twin, multi-agent, decision-architecture and ablation
evaluations, which need controlled scenarios with known ground truth.

## `external/india_mandi_prices/` — real Indian benchmark (ACTIVE)

| Field | Value |
|---|---|
| Dataset | India Agri-Commodity Daily Market Prices (AGMARKNET) |
| Source | data.gov.in resource `35985678-0d79-46b4-9ed6-6f13308a1d24`, Directorate of Marketing & Inspection (DMI), Ministry of Agriculture & Farmers Welfare, GoI |
| Licence | **Government Open Data License – India (GODL-India)** |
| Geography | India (multi-state) · `data_type: real` |
| Task | **price forecasting** + regional price analytics |

- `raw/` is **never modified** and is gitignored. Re-fetch with
  `python scripts/download_india_datasets.py` (public data.gov.in JSON API).
- `processed/*.csv` are committed, small, and produced *only* by
  `scripts/build_external_datasets.py` (adapter `ml/preprocessing/india_mandi_adapter.py`, seed 42).
- This source has **no transaction-quantity field**, so the canonical
  `units_sold` column carries the **daily modal price (INR/quintal)** being
  forecast; `price` is a 28-day backward rolling median (no leakage);
  `marketing_spend` / `promotion_flag` are `0` (absent in source — **not invented**).
- Register with `scripts/register_external_datasets.py`; benchmark-train with
  `scripts/run_external_benchmarks.py` (resulting models are `experimental`).

## `external/_retired_non_indian/` — RETIRED_NON_INDIAN_BENCHMARK

M5 (USA), UCI Online Retail (UK), Supermarket Sales (Myanmar). Retired from
active evaluation because they are not Indian. **Nothing was deleted** — the
processed CSVs, metadata and adapters remain, and all three benchmark scripts
reproduce them under an explicit `--retired` flag. See that folder's
`README.md` and `docs/INDIAN_DATASET_INTEGRATION_REPORT.md`.

## Honesty rules
- No external dataset feeds the SME Digital Twin / Causal Graph / Multi-Agent
  engines; those keep the synthetic controlled scenarios.
- Never present a `_retired_non_indian/` dataset as representing Indian SMEs.
- The Indian mandi dataset is agri-commodity **wholesale price** data — a
  genuine Indian benchmark, but not SME retail transactions. A real Indian
  transaction-level / churn dataset remains **pending** (open Indian data is
  price-series; transaction datasets are auth-gated). Do not overclaim.
- Distinguish `REAL INDIAN` vs `CONTROLLED SYNTHETIC` in every results table;
  never average across them.
