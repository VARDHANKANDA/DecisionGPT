# `data/` — DecisionGPT datasets

DecisionGPT's product & research focus is **Indian SMEs**. Data falls into
three categories that are **never silently mixed** (see
`docs/INDIAN_SME_DATA_ARCHITECTURE.md`):

```
SME-OWNED OPERATIONAL DATA   +   INDIAN PUBLIC CONTEXT   +   CONTROLLED SYNTHETIC
   (private, drives the             (context / benchmark /        (reproducible
    actual recommendations)          research validation)          ground truth)
```

**Synthetic ≠ real, non-Indian ≠ Indian, wholesale price ≠ SME retail** — the
Research Console and the paper must never blur them.

```
data/
├── platform/                     # SYNTHETIC_CONTROLLED (unchanged)
│   ├── forecasting/  #   platform-forecasting-v1
│   ├── churn/         #   platform-churn-v1  (the only churn dataset)
│   └── {marketing,pricing,inventory,causal,benchmarks}/  (.gitkeep)
│
├── external/
│   ├── india_ecommerce/          # INDIA_REAL_BUSINESS  (Benroshan CC0; real, small)
│   │       raw/(gitignored)  processed/  metadata.{json,md}
│   ├── india_customer_synthetic/ # SYNTHETIC_INDIAN_CONTEXT  (Kundan CC BY 4.0; simulated)
│   ├── india_agmarknet/          # INDIA_AGRICULTURAL_PRICE  (AGMARKNET; raw pull DATA_PENDING)
│   ├── india_context/
│   │   ├── festivals/            # INDIA_PUBLIC_CONTEXT  (holidays lib -> committed CSVs)
│   │   └── macro/                # INDIA_PUBLIC_CONTEXT  (RBI repo rate -> committed CSV)
│   └── _retired_non_indian/      # M5 (USA) / UCI (UK) / Myanmar — retired, reproducibility only
│
└── research_uploads/             # runtime store for Research-Console uploads (gitignored)
```

SME-owned operational data is **not** on disk here — it is per-business rows in
the application database, uploaded through `data_ingestion_service` and mapped
to the canonical types in `backend/app/services/canonical_schema.py`.

## `platform/` — synthetic, controlled  (`SYNTHETIC_CONTROLLED`)
Generated by `scripts/generate_platform_data.py` (seed 42). Back the
causal-graph, Digital-Twin, multi-agent, decision-architecture and ablation
evaluations, which need known ground truth. `evidence_level: SYNTHETIC`.
**Never removed or replaced.**

## `external/india_ecommerce/` — `INDIA_REAL_BUSINESS`
Benroshan Kaggle e-commerce dataset (CC0, downloaded anonymously). Real, small
(~500 orders / 12 months / 3 categories, 2018-19), **provenance unverified**
(uploader: "from my university, original author unknown"). Adapter
`ml/preprocessing/india_ecommerce_adapter.py`. Processed: category×state
analytics, target attainment, a small daily forecasting series (`price` is a
DERIVED implied unit price). No unit price / discount / ship date in the source
— not invented. See `docs/INDIAN_DATASET_EVALUATION.md`.

## `external/india_customer_synthetic/` — `SYNTHETIC_INDIAN_CONTEXT`
Kundan Kaggle customer-behaviour dataset (CC BY 4.0). The Kaggle page states it
is **simulated** → classified synthetic. Used only for a **standalone**
purchase-prediction benchmark (`scripts/run_india_customer_benchmark.py`) —
**not** an `MLModel`, **not** wired into the Training Center. `cart_abandoned`
is **not** churn. Never combined with real results.

## `external/india_agmarknet/` — `INDIA_AGRICULTURAL_PRICE`
AGMARKNET daily mandi **wholesale price** series (data.gov.in, GODL-India).
A supplementary Indian **price-series** benchmark — **not** SME retail
transactions. `raw/` gitignored, re-fetched by
`scripts/download_india_datasets.py`; `processed/` produced only by
`scripts/build_external_datasets.py` (adapter
`ml/preprocessing/india_agmarknet_adapter.py`, seed 42). The source has no
quantity field, so canonical `units_sold` carries the daily modal price;
`price` = 28-day backward rolling median (no leakage);
`marketing_spend`/`promotion_flag` = 0 (absent — not invented).
**Status: `DATA_PENDING`** (demo API key rate-limited; see
`india_agmarknet/metadata.md`).

## `external/india_context/` — `INDIA_PUBLIC_CONTEXT`
- **`festivals/`** — India festival & holiday calendar from the MIT `holidays`
  library (`holidays==0.103`, version pinned). Committed CSVs: event table +
  daily distance-to-festival features, 2019–2027.
- **`macro/`** — RBI policy repo-rate monthly series, compiled verbatim from
  published MPC resolutions. CPI/WPI/GDP are `PENDING` (same rate-limited
  data.gov.in API), not fabricated.

Optional exogenous context. **Never** joined into SME-private data in a way
that blurs provenance; never a target; never causal evidence.

## `external/_retired_non_indian/` — `RETIRED_NON_INDIAN`
M5 (USA), UCI Online Retail (UK), Supermarket Sales (Myanmar). Retired because
they are not Indian. **Nothing deleted** — processed CSVs, metadata and
adapters remain; all three scripts reproduce them under `--retired`. See that
folder's `README.md`.

## Honesty rules
- No external dataset feeds the SME Digital Twin / Causal Graph / Multi-Agent
  engines; those keep the synthetic controlled scenarios.
- AGMARKNET is agri-commodity **wholesale price** data — never described as
  Indian SME retail transactions.
- Missing SME data → a disabled capability with a reason, **never a fabricated
  value**.
- Distinguish `INDIA_REAL` / `INDIA_PUBLIC_CONTEXT` / `SYNTHETIC` in every
  results table; never average across them.
- A real Indian **transaction-level / churn** dataset is still **pending**
  (`docs/DATASET_DOWNLOAD_INSTRUCTIONS.md §2`).
